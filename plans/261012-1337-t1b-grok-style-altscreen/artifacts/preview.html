Grok-style alternate-screen TUI design preview (draft)

Each box is one terminal at the stated size. Every state except X1 is the whole alternate screen: header row, block pane, prompt pane, shortcut bar. There is no scrollback and no live region. X1 is the main screen after exit. Colors follow docs/tui-style-guide.md; the hook color is a proposed new role. Source: artifacts/sketch-gen.py, the same rows as design.md. All commands, paths and numbers are examples.

A1. Compact session, prompt focus

The whole TUI is on the alternate screen. Every step is one row: thinking `◆ Thought`, tools `◆ <Verb> <what>`, hooks `⚓` with a description row. The reply is expanded. Without a model description the tool row shows the command or the path.

A2b. Expand indicator on select and hover

A foldable block at its minimum fold shows `›` instead of `◆` (or `⚓`) when it is selected (here the failed test run) or under the mouse pointer (here the lint-guard hook). `→`/`l` expands it to Expanded, `←`/`h` collapses it. The reply and the user prompt keep their rows: they are not foldable.
