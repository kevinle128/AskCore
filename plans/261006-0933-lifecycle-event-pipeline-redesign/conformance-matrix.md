The "DeepSeek behavior" column uses DeepSeek words. The Ask columns use Ask words.

## Status values

- **follow**: Ask does what DeepSeek does. The Ask test checks the same behavior.
- **diverge-deliberate**: Ask changes what an upstream run or caller observes, on purpose, for a listed exception (D4, D11, D18, D20, D21, D26, D29, SNAPSHOT, PRECEDENCE, ALL-RESULTS, H10, JSON, BUSY, BOUNDS, CONT-BOUND, PROVIDER) or a named Ask rule with its reason. The Ask test checks Ask's behavior.
- **Ask-new**: Ask adds a capability that DeepSeek does not have. An upstream run would observe the same outcome. Any rule that changes an upstream outcome is `diverge-deliberate` (source audit, "Report precedence").
- **N/A**: outside this redesign. The reason says where it belongs.

Exception names: SNAPSHOT = tool definitions from the per-turn registry snapshot (user, 2026-10-05); PRECEDENCE = `End > Continue > Proceed`; ALL-RESULTS = a batch ends the cycle only when all results ask; JSON = the `ask -p --mode json` stream stays Pi-compatible; D21 = one Go coercion table for tool arguments (user, 2026-10-01; covered by D25 "decisions already recorded as decided"); BUSY = `Prompt` on an active Agent returns `ErrBusy` (Pi API, kept; user instruction 2026-10-06 for row 74); BOUNDS = the bounded follow ring, follower buffer and queue (red-team #14, accepted 2026-10-06); CONT-BOUND = at most 3 consecutive empty continuations (architecture report section 14; classified as changed behavior by the user on 2026-10-06); PROVIDER = a provider API rejects the DeepSeek form (rows 5b, SS11); D26-D29 = roadmap rows of 2026-10-06.
