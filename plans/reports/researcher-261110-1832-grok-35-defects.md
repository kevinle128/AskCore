## Evidence quality

- Strong (read the code path): N1, N3/N4, N5, N9, N21, N25, N26, N27, N29, N34.
- Weak or none: N10, N11 (Grok has no multi-provider replay), N12 (ACP id handling is in an unvendored crate; the cited precedent is the harness SDK, a different protocol).
- N2, N13, N17, N20, N22 to N24, N28, N30, N33, N35: one narrow search, nothing found. Say "not found", not "absent".

## Ranked takeaways

1. N29/N34: install signals before `initialize`; keep 130/143/129; a closed upstream is an error unless an end request was sent.
2. N26: integer parse first, float fallback only for whole values below 2^53.
3. N25: header probe plus pixel cap (16 MP is Grok's figure) before decode.
4. N1: judge emptiness on the folded final response; exempt content-filter stops.
5. N3/N4: normalize once at construction.
6. N27: set the truncation reason at the cap site.
