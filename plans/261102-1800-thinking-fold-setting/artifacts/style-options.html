Block pane: four style options (100×44)

The same turn in each option. Fixed in all four: the thin selection box (the reply is selected), colors from the existing palette, the 24h time on the first reply row, no table copy row, and no rail on thinking.

Option A: Grok: quiet and colored

Closest to Grok CLI. Thinking text is plain and muted, under the verb, with no rail. Headings lose the #, take a color by level, and are bold. Inline code is blue and bold with no backticks. Bullets are a muted •. Tables have a dim box. Code blocks have the code panel and no language row.
