L1. Idle: the status data is in the footer row

The decided layout. A slim header row holds only the logo, with a rule under it (D16). There is no model line, so the block pane starts with the first prompt band on row 3. Under the prompt pane and its rules, the footer row holds the directory, the model with its thinking level and the context use. It shows no logo, no link state and no session cost. The shortcut bar stays the last row.

F. Footer row forms

One footer row for each case, top to bottom: a session model; unknown context window; context at 90% or more (error role); state not known yet (meter only); no model; a long directory with the longest Anthropic model; a long directory with the longest model id. The footer row has no logo and no link state in any state (D14). These rows are not a screen: each row is the footer row of its own state.
